# Hut ab! – Pilzkarte Berlin/Brandenburg

Ergebnisse einer Claude-Cowork-Sitzung (11./12.10.2026): Auswertung des UFZ-Dürremonitors
(Oberboden) und von Niederschlagsdaten für die Pilzsuche rund um Berlin.

**Start mit Claude Code:** Ordner entpacken, darin `claude` starten (oder im Desktop-Tab „Code“
den Ordner öffnen). Die `CLAUDE.md` enthält Quellen, Farbcodes, Georeferenzierung und Ideen.

Schnelltest: `cd scripts && python3 geo.py` (braucht numpy, scipy) · `python3 build.py`
Karte ansehen: `output/Pilzkarte_Schorfheide_Chorin.html` im Browser öffnen.

Daten: UFZ-Dürremonitor (https://www.ufz.de/index.php?de=37937), Open-Meteo, © OpenStreetMap-Mitwirkende.
